# Auto Market - Веб-приложение для продажи автомобилей

## Описание
Веб-приложение для размещения объявлений о продаже автомобилей с возможностью управления статусами и фильтрации.

## Функциональность

- ✅ Просмотр всех объявлений на главной странице
- ✅ Создание новых объявлений с загрузкой фото
- ✅ Регистрация и авторизация пользователей
- ✅ Изменение статуса объявления (активно/продано)
- ✅ Просмотр и редактирование своих объявлений
- ✅ Фильтрация по характеристикам (марка, модель, год, цена, категории)
- ✅ Загрузка нескольких фотографий к объявлению
- ✅ Детальная информация об авто (кузов, привод, топливо, пробег и т.д.)

## Технологии
- **Backend**: Spring Boot, Hibernate
- **Frontend**: Thymeleaf, Bootstrap 5
- **Database**: H2 Database
- **Build Tool**: Maven
- **Миграции**: Liquibase

## Установка и запуск

1. Клонировать репозиторий:
```bash
git clone <repository-url>
cd cars
```

2. Собрать проект:
```bash
mvn clean package
```

3. Запустить приложение:
```bash
java -jar target/cars-1.0-SNAPSHOT.jar
```

4. Открыть в браузере:
```
http://localhost:8080
```

Приложение использует H2 Database с управлением миграциями через Liquibase. Таблицы создаются автоматически при запуске.

## Конфигурация
Основные настройки находятся в `application.properties`:

- Порт сервера: 8080
- База данных: H2 file-based
- Миграции: Liquibase

## API Endpoints

### Публичные маршруты:
- `GET /` - Главная страница
- `GET /auth/register` - Форма регистрации
- `POST /auth/register` - Регистрация пользователя
- `GET /auth/login` - Форма входа
- `POST /auth/login` - Аутентификация
- `GET /posts/{id}` - Просмотр объявления

### Защищенные маршруты (требуют авторизации):
- `GET /posts/create` - Форма создания объявления
- `POST /posts/create` - Создание объявления
- `GET /posts/my` - Мои объявления
- `POST /posts/{id}/sell` - Отметить как проданное
- `POST /auth/logout` - Выход из системы

## Особенности реализации:

1. ✅ **Без Spring Data** - используется чистая конфигурация Hibernate через SessionFactory
2. ✅ **Трехслойная архитектура** - контроллеры, сервисы, репозитории
3. ✅ **Валидация форм** - Spring Validation с кастомными DTO
4. ✅ **Загрузка файлов** - поддержка multiple upload с сохранением в файловую систему
5. ✅ **Управление сессиями** - через HttpSession и кастомные фильтры
6. ✅ **Расширенная информация об авто** - категории, характеристики, фильтрация
7. ✅ **Миграции БД** - управление через Liquibase

## Архитектурные детали:

### Репозитории:
- Каждая модель имеет отдельный репозиторий (`CarRepository`, `PostRepository`, `UserRepository` и т.д.)
- Используется общий `CrudRepository` для работы с Hibernate `SessionFactory`
- Ручное управление транзакциями

### Сервисы:
- `PostService` - бизнес-логика объявлений
- `UserService` - управление пользователями
- `EngineService` - работа с двигателями

### Контроллеры:
- `IndexController` - главная страница
- `PostController` - управление объявлениями
- `AuthController` - регистрация и аутентификация

### Фильтры:
- `SessionFilter` - управление сессиями пользователей
- `AuthorizationFilter` - проверка прав доступа к защищенным маршрутам
